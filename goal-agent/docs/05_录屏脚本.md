# 3 分钟录屏脚本（本人开麦）

> 录屏必须由本人完成并开麦讲解；下面的台词是提词器，不是自动配音。建议一次录完，终端字号 18-20，深色主题，避免泄露密钥/真实数据。

## 录前 30 秒准备

```bash
cd goal-agent
python scripts/generate_data.py
python -m bizgoal demo
# 或者按顺序自动跑正常/降级/失败/坏数据/不可达：
# bash scripts/demo.sh
```

打开 `runs/demo/report.md` 备用。确认：

- 基线：毛利率 **25.00%**、DSO **48.50 天**、应收 **1,333 万**；
- 目标：毛利 **+3pp → 28.00%**、DSO **≤45 天**；
- 预测：**28.25% / 44.24 天**，4 个动作，自检 12/12。

## 备选台词（如果时间紧）

- 口径一句话：**收入按开票日所在期间、回款按实际到账、账龄从开票日起算。**
- 闭环一句话：**+3pp 和 45 天 → 拆成毛利缺口 25.56 万、回款缺口 96.23 万 → 4 个动作 → 28.25% / 44.24 天 → 12 项校验。**
- 兜底一句话：**坏数据停、模型挂降级、动作失败重规划、目标不可达报缺口。**

## 演示命令清单

```bash
cd goal-agent

# 1. 造数
python scripts/generate_data.py

# 2. 正常闭环
python -m bizgoal demo

# 3. 模型不可用，规则降级
python -m bizgoal run --out runs/demo-llm --chaos llm-down

# 4. 动作失败，重规划
python -m bizgoal run --out runs/demo-recover --chaos action-fail

# 5. 坏数据，退出码 2
python -m bizgoal run --out runs/demo-bad --chaos data-corrupt; echo "exit=$?"

# 6. 目标不可达，退出码 3
python -m bizgoal run --out runs/demo-hard --goal "本月毛利提 12 个点，回款周期压到 20 天以内"; echo "exit=$?"

# 7. 模型连通性（配置密钥后）
python -m bizgoal llm-check
```

## 录屏注意

- 不展示 `DEEPSEEK_API_KEY`、真实客户数据或内部聊天内容。
- 如果现场网络不可用，直接讲解 `--chaos llm-down` 的降级路径，并说明接入 DeepSeek/Qwen 的命令。
- 3 分钟是上限，宁可少讲一个动作，也要把「口径、闭环、兜底」讲全。
